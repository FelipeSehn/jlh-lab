# Justice League Heroes — Technical Lab (JLH Lab v0.1)

🌐 **Live Site:** [justice-league-heroes-lab.vercel.app](https://justice-league-heroes-lab.vercel.app/) | 🚧 **Status:** `v0.1 — Early Access / Work in Progress`

An interactive technical documentation hub, damage calculator, and mechanics lab dedicated to **Justice League Heroes** (PS2 / PSP / Xbox). Built in public to document hidden game formulas, character stats, and emulation setups.

---

## Current Features & Roadmap

- [x] **Interactive Damage Calculator** — Real-time damage and attribute scaling simulation.
- [x] **Automated CI/CD Pipeline** — Continuous deployment via GitHub + Vercel.
- [ ] **Damage Calculator Expansion** — Full character formulas, modifiers, and edge cases.
- [ ] **Complete `en-US` Localization** — Standardizing all interface labels and technical notes.
- [ ] **Beginner's Emulation Guide** — Optimal settings for PCSX2 and PPSSPP.
- [ ] **Character Frame Data & Tier Breakdown** — Deep-dive mechanics per hero.

---

## Architecture

This project is intentionally built as a zero-dependency, **single-file architecture (`index.html`)** using vanilla HTML5, CSS3, and JavaScript. This ensures instant load times, offline portability, and clean version control.
